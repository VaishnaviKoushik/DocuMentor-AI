# **App Name**: DocuMentor AI

## Core Features:

- Code Parsing: Parse Python code using AST to extract function, class, and module definitions.
- Dependency Analysis: Understand project-wide dependencies to provide context-aware explanations.
- Docstring Generation: Generate reStructuredText (reST)-formatted docstrings with meaningful summaries, parameter types, and return values based on code and naming conventions using a tool.
- README Generation: Produce README.md files that summarize folder contents, module relationships, and their purpose.
- Codebase Summary: Generate a top-level README that explains the full structure and purpose of the codebase.
- Improvement Suggestions: Suggest improvements or point out missing docstrings within the code using a tool.
- Reporting Undocumented Functions: Flag confusing or undocumented public functions using a tool.

## Style Guidelines:

- Background color: Off-white (#F8F9FA) to provide a clean, professional look.
- Primary color: Dark blue (#2E3192) to convey trust and intelligence. This is reminiscent of technical diagrams and blueprints.
- Accent color: Teal (#008080) to highlight key information and CTAs. 
- Body font: 'Inter', a sans-serif font, will be used for body text to ensure readability and a modern appearance.
- Headline font: 'Space Grotesk', a sans-serif font, providing a techy, scientific feel.
- Code font: 'Source Code Pro' for displaying code snippets.
- Use simple, clear icons to represent different documentation elements, such as modules, classes, and functions.
- Use a clean, well-structured layout with clear separation of sections to enhance readability and ease of navigation.
- Subtle transitions for loading new documentation and interactions.
